带画面的版本在 `storyboard.html`（可交互：可以开关小红书界面遮挡区），静态预览在 `preview/`。时间是暂定的，配音生成后会按真实音频重新卡点。

**画面规格**：1080×1920，30 fps。浅灰点阵底，墨色线条。钴蓝 = 正在执行，琥珀 = 没解决，红 = 被拒绝。每种颜色都配一个形状（▶ 实线 / ! 虚线 / ✕ 栅栏），不只靠颜色区分。
**版式**：所有文字都放在 y 168–1330 之间。字幕框在 y 1172–1304，x 64–916。右侧按钮栏区域（x>940、y>820）不放字。1330 以下只留点阵底纹。
**字号**：标题 80px（开场 88px）、图中标签 44px、字幕 52px、等宽代码 33–36px，最小 28px。
**同一张图**：模型、运行系统外框、检查栅栏、三个工具、侧边栏位、文件夹（20 格）和 .csv，从 S3 起每一帧都在**固定位置**，只增加东西或改变状态，不重新排版。
